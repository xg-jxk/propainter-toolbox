ProPainter 视频修复工具箱 v1.3.13（便携版）
==========================================

本压缩包只有"界面外壳"（约 110 MB）。
真正的运行环境（约 2.5 GB：PyTorch + 模型权重）在第一次运行时自动下载安装。

【第一次使用】
1. 把整个文件夹解压到磁盘上，例如 D:\ProPainterToolbox
   不要放在 C:\Program Files —— 安装过程要在这个目录里写入 .venv 和模型
2. 双击 ProPainterToolbox.exe
3. 首次会弹出「使用条款」：阅读后勾选同意，点「同意并继续」
4. 如果顶部显示「缺少运行时」，点【安装运行时】
   它会自动执行 setup.ps1：装依赖、下载 PyTorch（约 2.4 GB）、
   模型权重（190 MB）、Real-CUGAN（45 MB）
   视网络 10~30 分钟；中途可以关窗口，下次会跳过已完成的部分
5. 状态变成「运行时就绪」后，就可以把视频拖进去了

【需要什么】
- Windows 10 1803+ / Windows 11（依赖系统自带的 tar 和 curl）
- 磁盘剩余 ≥ 8 GB
- 能访问 pypi、download.pytorch.org、github（国内网络会自动走镜像）
- NVIDIA 显卡 + 驱动 ≥ 527.41（没有也能跑，但区域修复会非常慢）
- 本目录有写权限（不要放系统盘的保护目录）

【怎么用】
- 把 mp4 拖进虚线框 → 选模式（区域修复 / 超分 / 区域修复+超分）→ 开始处理
- 输出默认在源视频同目录，后缀 _已修复.mp4 / _2x.mp4 / _已修复_2x.mp4
- 进度是逐帧真实的，随时可以「取消」（立即结束推理进程并清理临时文件）
- 参数与窗口大小会记住，存在 %LOCALAPPDATA%\ProPainterToolbox\config.json

【常见问题】
- 杀毒软件报毒：exe 未签名，PyInstaller 打包的正常误报，加入信任即可
- 安装中断：重新双击 exe 再点一次「安装运行时」，已完成步骤会跳过
  详细日志在 setup.log
- 移动了文件夹：.venv 里记录的是绝对路径，移动后请重新点「安装运行时」
- 想看命令行用法：同目录下 区域修复.cmd / 超分.cmd / 修复超分.cmd 仍然可用
- 没有显卡/显存不够：把参数里的「分段 subvideo」从 40 降到 20
